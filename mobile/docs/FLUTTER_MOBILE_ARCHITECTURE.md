Document ID: DOC-104  
Version: 0.1.0

## Purpose

Defines mobile architecture using Flutter.

## Initial Platform

Android first, iOS later.

## Mobile Use Cases

- Review applications.
- View resumes.
- Practice interview answers.
- Track follow-ups.
- Receive reminders.
- Update profile details.

## Constraint

Mobile should not become a separate backend. It should use CareerOS APIs.
