## Purpose

The API layer exposes CareerOS capabilities to desktop, mobile, web, browser extensions, and local automation tools.

## API Style

- REST first
- OpenAPI documented
- JSON request/response
- Localhost-first deployment
- Authentication optional for local single-user mode
- Token-based auth for multi-client mode

## Initial API Groups

- `/health`
- `/profile`
- `/resume`
- `/jobs`
- `/applications`
- `/documents`
- `/ai`
- `/plugins`
- `/settings`
