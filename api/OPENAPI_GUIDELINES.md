Document ID: DOC-082  
Version: 0.1.0  
Status: Draft  
Milestone: 08B

## Purpose

Defines API documentation standards.

## Rules

- Every endpoint must have summary and description.
- Every request body must use a typed schema.
- Every response must be documented.
- Error responses must be documented.
- OpenAPI output should be available from the local backend.
