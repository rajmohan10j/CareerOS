# Database

Document ID: DOC-024  
Version: 0.1.0  
Status: Draft

## Purpose

Defines the local-first data storage approach for CareerOS.

## Default Database

SQLite is the default database for local installations.

## Future Database

PostgreSQL may be supported later for team, cloud, or synced deployments.

## Data Ownership

All user career data belongs to the user and must be exportable.
