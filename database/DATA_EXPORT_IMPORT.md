# DATA_EXPORT_IMPORT

Document ID: DOC-084  
Version: 0.1.0  
Status: Draft  
Milestone: 08B

## Purpose

Defines import/export strategy.

## Export Formats

- JSON
- Markdown
- CSV
- ZIP archive

## Export Scope

Users should be able to export:

- profile
- resumes
- jobs
- applications
- documents metadata
- settings

## Import Scope

Initial import should support:

- profile JSON
- resume Markdown
- job descriptions
- application tracker CSV

## Rule

User data must remain portable.
