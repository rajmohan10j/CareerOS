# DESKTOP_APP_SPEC

Document ID: DOC-041  
Version: 0.1.0  
Status: Draft

## Purpose

Defines desktop application requirements.

## Core Screens

- Dashboard
- Master Candidate Profile
- Resume Manager
- Job Tracker
- Application Manager
- Interview Coach
- AI Settings
- Plugin Manager
- Logs and Diagnostics

## Requirements

- Must run on Windows.
- Must connect to local backend.
- Must work offline.
- Must not require paid AI services.
- Must expose model status clearly.
