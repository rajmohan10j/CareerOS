## Purpose

Defines the Windows-first desktop architecture using Tauri.

## Responsibilities

- Launch local UI.
- Connect to local backend.
- Manage user settings.
- Provide desktop notifications.
- Expose local logs/diagnostics.

## Why Tauri

- Smaller footprint than Electron.
- Better fit for low-resource machines.
- Cross-platform future support.
