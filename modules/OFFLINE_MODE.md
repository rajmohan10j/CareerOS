# OFFLINE_MODE

Document ID: DOC-108  
Version: 0.1.0  
Status: Draft  
Milestone: 08D

## Purpose

Defines offline-first behavior.

## Offline Capabilities

- View and edit profile.
- View resumes.
- Track jobs.
- Generate resumes if local AI is available.
- Search local data.
- Export data.

## Sync

Cloud sync is future optional functionality and must not be required.
