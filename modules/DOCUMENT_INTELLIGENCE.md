# DOCUMENT_INTELLIGENCE

Document ID: DOC-033  
Version: 0.1.0  
Status: Draft

## Purpose

Document Intelligence extracts structured data from resumes, certificates, job descriptions, screenshots, and uploaded documents.

## Components

- PDF parser
- DOCX parser
- OCR engine
- Vision model integration
- Metadata extractor
- Entity extractor

## Supported Inputs

- PDF
- DOCX
- Markdown
- Images
- Screenshots
- Plain text

## Output

Normalized structured records that feed the Master Candidate Profile and RAG system.
