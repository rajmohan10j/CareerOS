# RESUME_ENGINE

Document ID: DOC-032  
Version: 0.1.0  
Status: Draft

## Purpose

The Resume Engine generates, optimizes, versions, and exports resumes using the Master Candidate Profile.

## Capabilities

- Generate ATS resume
- Tailor resume to job description
- Track resume versions
- Export Markdown, PDF, DOCX, HTML
- Preserve factual consistency
- Highlight skill gaps
- Suggest impact bullet improvements

## Inputs

- Master Candidate Profile
- Job Description
- Target Role
- Resume Style
- Output Format

## Outputs

- Tailored resume
- ATS score estimate
- Improvement notes
- Version metadata

## Constraint

The Resume Engine must not invent experience, employers, education, or achievements.
