## Purpose

Defines how specialized AI agents collaborate inside CareerOS.

## Agents

- Resume Agent
- Job Evaluation Agent
- Interview Agent
- Autofill Agent
- Learning Agent
- Recruiter CRM Agent
- Documentation Agent
- QA Agent

## Rule

Agents must use shared platform services and must not bypass governance, audit logging, or user approval rules.
