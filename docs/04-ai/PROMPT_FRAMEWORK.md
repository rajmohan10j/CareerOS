## Purpose

Defines reusable prompt architecture.

## Prompt Types

- System prompts
- Agent prompts
- Task prompts
- Review prompts
- Testing prompts
- Safety prompts

## Prompt Structure

Each prompt should include:

- Role
- Objective
- Inputs
- Constraints
- Output format
- Validation rules
- Safety rules

## Rule

Prompts must not encourage fabrication of user achievements, employment, qualifications, or application details.
