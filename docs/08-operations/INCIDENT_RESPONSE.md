Document ID: DOC-124  
Version: 0.1.0  
Status: Draft  
Milestone: 08E

## Purpose

Defines how incidents are handled.

## Incident Types

- Security vulnerability
- Data loss risk
- Broken release
- Plugin abuse
- Critical AI behavior issue

## Response Steps

1. Confirm issue.
2. Assess severity.
3. Mitigate.
4. Communicate.
5. Patch.
6. Document lessons learned.
