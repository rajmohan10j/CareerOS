# ACCESSIBILITY_STANDARDS

Document ID: DOC-114  
Version: 0.1.0  
Status: Draft  
Milestone: 08D

## Purpose

Defines accessibility expectations.

## Standards

- Keyboard navigation
- Screen reader labels
- Clear contrast
- Responsive layouts
- Form validation messages
- Avoid color-only status indicators

## Goal

CareerOS should be usable by a broad range of users across devices.
