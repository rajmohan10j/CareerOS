## Purpose

Defines UX principles.

## UX Principles

- Clear before clever.
- User remains in control.
- Show AI confidence when relevant.
- Make data sources visible.
- Never hide critical automation.
- Provide undo where practical.

## Key UX Patterns

- Review before apply.
- Confirm before external action.
- Explain AI-generated changes.
- Highlight missing data.
