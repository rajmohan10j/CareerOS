# BRANCHING_STRATEGY

Document ID: DOC-117  
Version: 0.1.0  
Status: Draft  
Milestone: 08E

## Branches

- `main`: stable baseline
- `develop`: active development
- `feature/*`: new features
- `fix/*`: fixes
- `docs/*`: documentation work
- `release/*`: release preparation

## Rule

Direct commits to `main` should be avoided after public release.
