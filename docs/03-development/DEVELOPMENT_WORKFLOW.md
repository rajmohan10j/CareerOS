Status: Draft  
Milestone: 08E – Engineering Operations Pack

## Purpose

Defines the standard development workflow for CareerOS.

## Workflow

1. Read current task.
2. Read relevant architecture/specification files.
3. Confirm dependencies.
4. Implement the smallest useful increment.
5. Add or update tests.
6. Update documentation.
7. Run checks.
8. Commit with clear message.
9. Update execution status.

## Rule

No implementation task is complete without tests and documentation.
