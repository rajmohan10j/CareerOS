## Purpose

Defines performance expectations.

## Local Machine Constraint

CareerOS should support low-resource machines where possible, including 8 GB RAM systems.

## Guidelines

- Avoid unnecessary background services.
- Keep local model usage configurable.
- Provide low-resource AI profiles.
- Defer heavy processing.
- Cache safely where useful.
