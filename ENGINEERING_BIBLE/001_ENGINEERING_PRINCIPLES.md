# Engineering Principles

Document ID: EB-001  
Version: 0.1.0  
Status: Draft

## Core Principles

- Local-first by default
- Open-source first
- Free model support for all core features
- Privacy before convenience
- Human approval for critical actions
- Modular and plugin-ready design
- Documentation before implementation
- Testable architecture
- No vendor lock-in
- Clear ownership of user data

## Development Rule

If a design decision conflicts with these principles, the decision must be documented in an ADR before implementation.
