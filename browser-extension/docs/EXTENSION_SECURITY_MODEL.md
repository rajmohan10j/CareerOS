# EXTENSION_SECURITY_MODEL

Document ID: DOC-107  
Version: 0.1.0  
Status: Draft  
Milestone: 08D

## Purpose

Defines browser extension security.

## Rules

- Request minimum permissions.
- Do not collect unrelated browsing data.
- Do not store credentials unless explicitly designed and approved.
- Do not submit applications automatically.
- Send only necessary page context to the local backend.
- Show user what will be filled before filling.

## Sensitive Fields

Require explicit confirmation:

- salary expectation
- work authorization
- personal address
- phone number
- diversity/equal opportunity questions
