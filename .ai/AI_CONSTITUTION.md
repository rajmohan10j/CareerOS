# AI Constitution

This document defines the immutable principles governing CareerOS development. Every human contributor and AI development agent must follow these rules.

## Core Principles

1. Documentation First
2. Architecture Before Implementation
3. Local-First by Default
4. Privacy First
5. Open Source First
6. Free AI Models Must Support All Core Features
7. Human Approval for Critical Actions
8. No Vendor Lock-in
9. Modular, Plugin-Based Design
10. Transparent Development

## AI Development Rules

- AI may generate code, documentation, tests, and reviews.
- AI must not make architectural changes without documented approval.
- AI-generated code requires human review before merge.
- Every major feature requires documentation and tests.

## Privacy Rules

- No automatic upload of user data.
- No telemetry enabled by default.
- User data remains user-owned.

## Architecture Rules

- Every significant decision requires an ADR.
- Backward compatibility is preferred.
- Public interfaces should remain stable.

## Contributor Responsibilities

All contributors must:
- Read the foundational documents.
- Follow coding and documentation standards.
- Respect governance and security policies.
